Part D: What I Learnt

  1. The action attribute tells the form where to send the information after I submit it.
  2. The method attribute tells the form how the information should be sent.
  3. GET is commonly useful for a search form because the search information can appear in the URL, so it can be easily shared or bookmarked.
  4. POST might be used for a registration form because it is suitable for sending information to a server for processing.
  5. No. Using POST does not automatically make information secure. HTTPS and other security measures are still needed to protect the information.
